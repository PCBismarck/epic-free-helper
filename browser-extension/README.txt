Epic 周免领取助手 — Windows Chrome / Edge

1. 在已登录 Epic 的 Windows Chrome 地址栏输入 chrome://extensions
   Edge 使用 edge://extensions
2. 打开“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择整个 EpicFreeHelper 文件夹（其中包含 manifest.json）。
4. 点击扩展图标，再点“领取本周游戏”。
5. 只有当本轮全部游戏确认已领取/已拥有后，才能开启“每天23:35自动检查”。

请保留安装文件夹；运行时不需要 WSL、Python、Node、Docker 或模型 API。
浏览器必须开启才能运行，关闭或休眠期间无法按时执行。
每轮最多创建一个领取标签页，顺序检查当前官方PC周免，最长5分钟。
已拥有的游戏仍会打开商品页核对当前账号；在同一新页面稳定确认“已在库中”后，
显示“已拥有·已跳过”并继续下一款，不点击获取或下单，也不额外刷新。
只允许零元商品；旧版结账核验零总额，新版免费领取页核验单个商品标识、
游戏名、紧邻的零元价格及免费内容说明，刷新商品页确认入库才记成功。
遇到验证/登录/未知页面时停止并关闭定时，保留本轮标签页让你处理。
处理后关闭领取页或点“停止本次任务”，再手动运行；不会自己重试。
不会打开额外浏览器，不使用调试连接，不读取/导出Cookie或密码。
不发送通知、不调用外部模型、不操作其它游戏平台或第三方聚合。

更新到1.0.2后，在扩展管理页点“重新加载”。若有中断记录，先点“停止本次任务”
清除记录、关闭旧领取页，再手动试领。
验证范围：离线逻辑及真实浏览器中两款已拥有游戏的完整跳过流程，获取/提交均为零。
你的Windows账号上的新版完整流程仍需重新加载后运行核验。
