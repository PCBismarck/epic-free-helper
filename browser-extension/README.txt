Epic 周免领取助手 — Windows Chrome / Edge
版本：1.0.8

自动检查并领取 Epic PC 周免游戏，支持已拥有游戏跳过和每日定时检查。

安装与使用
1. 在 Chrome 打开 chrome://extensions，或在 Edge 打开 edge://extensions。
2. 开启“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择包含 manifest.json 的扩展目录；使用仓库源码时选择 browser-extension 目录。
4. 在同一浏览器中登录 Epic，点击扩展图标，再点“领取本周游戏”。
5. 定时检查默认关闭。本轮全部游戏确认已领取或已拥有后，可开启每天北京时间 23:35 的自动检查。

请保留安装目录。更新文件后，在扩展管理页点击“重新加载”。
浏览器需要保持运行；关闭浏览器或电脑休眠时，任务无法按时执行。

领取规则
每轮使用一个领取标签页，依次检查最多 10 款官方 PC 周免游戏，最长运行 5 分钟。
确认游戏已在库中后，显示“已拥有·已跳过”并继续下一款。
商品页就绪、结账加载、提交后等待入库分别最多等待 60 秒；提交后重新计时，超时会提示具体环节。
提交后持续检查结账子页面，在 60 秒窗口内等待安全验证结果；短暂验证窗口消失后继续确认入库。
如果页面要求人工验证，请只完成验证，让扩展继续检查；超时则保留原页面，不重复提交或自动刷新。
官方促销接口单次请求超时为 15 秒；网络较差时可能暂停，需要检查后重新运行。
领取前核验商品身份和零元价格，领取后重新打开商品页确认入库。
达到整轮 5 分钟上限，或遇到登录、人工验证、无法识别的页面时暂停，关闭定时并保留标签页供处理。
处理完成后点击“停止本次任务”，再手动运行。

工具栏提示
将扩展固定到工具栏即可看到角标：红色 ! 表示失败或待处理，绿色 ✓ 表示最近一轮全部确认在库，蓝色 … 表示运行中。
黄色 – 表示手动停止或本轮无符合条件的游戏；存在失败记录时仍显示红色。尚未运行时无角标。
鼠标悬停可查看时间、失败原因和定时开关状态；点击扩展查看详情不会清除失败提示。
角标会在浏览器或扩展重启后恢复，表示最近一轮结果，不代表新一周已领取。

本地数据
扩展使用浏览器当前的 Epic 登录状态，不收集密码或导出 Cookie。
设置、任务进度和游戏结果保存在浏览器的扩展本地存储中。
